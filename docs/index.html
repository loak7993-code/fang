The whole language fits in one sitting

Under 30 reserved words. Ten of them cover a beginner's first hour. Type annotations only on function parameters; everything else is inferred.

# fib.leo — runs with: leo run fib.leo
import math

struct Vec2:
  x: float
  y: float

fn Vec2.norm(self) -> float:
  return math.sqrt(self.x * self.x + self.y * self.y)

fn fib(n: int) -> int:
  if n < 2:
    return n
  return fib(n - 1) + fib(n - 2)

fn main():
  let v = Vec2(3.0, 4.0)
  print(f"norm = {v.norm()}")
  let xs = [3, 1, 2]
  xs.sort()
  print(xs[0], xs[-1], len(xs))

What you get

Native binaries

One command produces a standalone executable. No interpreter, no VM, no runtime pauses. Reference counting releases memory deterministically at function exit.

The whole C ecosystem

Declare any fixed-arity C function and call it. GUI toolkits, databases, syscalls, kernel interfaces: extern fn reaches all of them.

Freestanding builds

--freestanding compiles with no runtime and no libc, with inline asm for the parts hardware needs. Target any triple your toolchain knows.

Packages without infrastructure

A package is a git repository. leo add clones and pins it. No registry, no account, no server to maintain.

One canonical style

leo fmt formats everything the same way. Style arguments end here.

A tutorial that cannot rot

Every code block in the tutorial is extracted and executed by the test suite. If an example breaks, the build fails.

Standard library

Written in Leo itself, embedded in the compiler binary. The JSON parser is pure Leo, which keeps the language honest.
